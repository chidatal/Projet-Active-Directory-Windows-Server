# Projet-Active-Directory-Windows-Server
Projet de mise en place et d'administration d'une infrastructure Active Directory sous Windows Server 2022.

## 📌 Présentation

Ce projet présente la mise en place et l'administration d'une
infrastructure Active Directory sous Windows Server 2022 dans un
environnement virtualisé (vmware esxi).

## 🎯 Objectifs

- Installer et configurer Active Directory Domain Services (AD DS)
- Configurer le DNS
- Coonfigurer DHCP
- Créer et organiser les unités d'organisation (OU)
- Créer des utilisateurs et des groupes
- Configurer les permissions et les partages
- Mettre en place un serveur de fichiers
- Mettre en place un système de fichiers distribués (DFS)
- Configurer un espace de noms DFS
- Configurer la réplication DFS (DFSR)
- Créer et appliquer des stratégies de groupe (GPO)
- Déployer automatiquement un lecteur réseau
-  Identifier les cinq rôles FSMO d'Active Directory
- Vérifier la répartition des rôles FSMO
- Transférer les rôles FSMO entre contrôleurs de domaine
- Vérifier le bon fonctionnement après le transfert
- Configurer les dossiers personnels (Home Folders) pour les utilisateurs
- Attribuer automatiquement un dossier personnel à chaque utilisateur
- Configurer une sauvegarde du serveur
- Ajouter un deuxième contrôleur de domaine
- Configurer et tester une relation d'approbation (Trust) entre domaines
- Tester l'accès depuis un poste client
- Mettre en place l'audit des activités Active Directory
- Auditer les connexions et les événements de sécurité
- Consulter et analyser les journaux d'événements Windows
-  Utiliser les consoles de gestion Windows (MMC) pour administrer l'infrastructure
- Administrer Active Directory, les stratégies de groupe, les utilisateurs et les ordinateurs depuis les consoles de gestion

## 🖥️ Environnement technique

- Windows Server 2022
- Active Directory Domain Services
- DNS
- DHCP
- Group Policy (GPO)
- Serveur de fichiers
- DFS
- Windows Server Backup
- Environnement virtualisé
